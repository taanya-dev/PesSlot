# PesSlot – Smart Parking Management System

## Project Overview
PesSlot is a web-based smart parking management system designed to address parking space management challenges in college campuses. The system enables users to view real-time parking slot availability and supports efficient allocation of parking spaces, helping reduce congestion and time spent searching for parking.

## Key Features
- Real-time parking slot availability monitoring  
- Efficient and organized parking slot allocation  
- User-friendly web interface  
- Designed specifically for college campus environments  

## Technology Stack
**Frontend**
- HTML
- CSS
- JavaScript
- React

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB

## Use Case
PesSlot helps students, faculty, and staff quickly identify available parking spaces within the campus, improving parking efficiency and reducing unnecessary traffic congestion.

## Project Status
Completed. This project has been successfully implemented as part of academic coursework and fulfills all intended objectives.

## Setup Instructions (Optional)
1. Clone the repository  
2. Install dependencies using `npm install` in both `Frontend` and `Backend` folders  
3. Configure environment variables in a `.env` file  
4. Run backend using `npm start`  
5. Run frontend using `npm start`
