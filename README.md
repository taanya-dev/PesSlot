#  PesSlot 

##  Project Overview
PesSlot is a web-based Smart Parking Management System developed to address parking space management challenges in college campuses. The system enables users to monitor real-time parking slot availability and supports efficient allocation of parking spaces, helping reduce congestion and time spent searching for parking.

---

##  Key Features
- Real-time parking slot availability monitoring
- Efficient and organized parking slot allocation
- User-friendly web interface
- Campus-focused parking management solution
- Backend API integration for data handling
- Database storage for persistent parking records
